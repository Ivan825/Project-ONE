# Project ONE — Research & Execution Plan (v2)

*Supersedes the August 2026 exploratory proposal for execution purposes. The full narrative version exists as `Project_ONE_Revised_Plan_v2.docx`; the original 22-page proposal contains the complete philosophical motivation and long-term programme.*

## Premise (unchanged)

Build a digital world in which many temporary, locally limited agents collectively create a larger evolving network; let a global observer measure and remember the network's condition; feed that self-description back into the agents; measure what changes — including when the self-description is false.

```
local actions → global condition → measurement → self-model → broadcast → changed local actions
```

## What v2 changes

v1 was a research programme; v2 is a wedge. One buildable prototype, one flagship experiment with a defensible novelty claim, one narrow paper, one deliberate outreach path. The novelty burden is carried by the two elements without clean precedent:

1. **The false self-model (flagship).** Mean-field physics never lies to its particles. Broadcasting a deliberately inaccurate self-description and measuring whether the system converges toward it (self-fulfilling) or away (self-defeating) connects to reflexivity in markets, metrics-gaming in organizations, and narrative feedback on platforms.
2. **Continuity under total turnover (Paper 2).** Replace 100% of agents; measure which structural, informational, behavioural and functional properties persist — identity as a bundle of separable continuities.

## Flagship claim (Paper 1)

> A distributed adaptive system can be causally altered by a compressed representation of itself — and the effect persists, in characteristic directions, even when the representation is false.

## Conditions

| Condition | Observer | Agents receive | Role |
|---|---|---|---|
| A — Local Only | no | nothing | baseline |
| B — Observed but Blind | yes | nothing | controls for measurement |
| C — True Feedback | yes | accurate S(t) | main treatment |
| F — False Feedback | yes | distorted S(t) | flagship |
| N — Noise Feedback | yes | matched-bandwidth random signal | kills "any broadcast" objection |

Deferred from v1: D (historical feedback), E (homeostatic controller), G (partial observer).

## Pre-registered primary outcomes (frozen before first full run)

1. Recovery half-life after standardized shock (targeted hub removal)
2. Fragmentation trajectory
3. Cooperation rate (costly helping per capita)
4. Self-model correspondence (in F: convergence toward vs. away from the false description)

Everything else logged = secondary/exploratory, labelled as such.

## Reach

Repo first (one-command reproduction of every figure), preprint second, peer review third (ALIFE → Artificial Life / JASSS). Cold-email 5–10 researchers whose work this builds on, asking for criticism. Seminar circuit for complex-systems groups. Pitch per audience:

- **ALife/complex systems:** a controlled laboratory for reflexive self-modelling with ablations that isolate the mechanism.
- **AI/ML & safety:** LLM-agent collectives are already fed dashboards about themselves; nobody has clean causal evidence of what self-measurement does to an agent population.
- **General:** when a system is told a false story about itself, does the story come true?

## Risks

- **Breadth creep** → outcomes and conditions frozen; all else exploratory.
- **Trivial effect** (C ≈ N) → that is itself the published finding.
- **"It's just mean-field coupling"** → confronted in related work; F-condition has no mean-field analogue.
- **Metaphysics leakage** → one motivation paragraph; the word "consciousness" never appears in a claim.

## Deferred programme (nothing lost)

Historical/global memory, homeostatic regulation, competing observers, observer inside the world, nested selves, distributed real nodes, human/AI participation with full ethics framework — each returns only after the flagship establishes the minimal loop matters.
